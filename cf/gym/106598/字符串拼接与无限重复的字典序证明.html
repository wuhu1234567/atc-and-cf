字符串 · 全小数版证明

为什么比较 st 与 ts，
等价于比较 s 与 t 的无限重复？

有限字符串和无限字符串，都用小数来表示。先说明这种表示为什么保持字典序，再比较两组小数的差。

要证明什么？

设 s、t 是非空字符串，st 表示把 t 拼在 s 后面，s∞ = ssss… 表示无限重复。

st < ts   ⇔   s∞ < t∞

两边同时换成“=”或“>”，结论也成立。这里的大小关系都是字典序。

1. 统一规则：把字符串放到小数点后

先只考虑三个字母，规定 a → 1、b → 2、c → 3，使用熟悉的十进制。把每个字符换成一个数字，放在小数点后，得到的小数记作 F：

字符串对应的小数含义
abF(ab) = 0.12有限小数，后面补无限个 0
abaF(aba) = 0.121有限小数，后面补无限个 0
ababab…F(ababab…) = 0.121212…无限循环小数

有限字符串也可以用小数表示。例如，abc < acb 对应 0.123 < 0.132。本篇从头到尾都采用这种表示，不切换到整数编码。

无限小数表示一个实数：例如 0.121212… 是有限小数 0.12、0.1212、0.121212、… 逐渐接近的值，即它们的极限。

2. 为什么比较小数，能代表比较字典序？

字典序由第一个不同字符决定。小数也需要满足相同性质：该位产生的差，不能被后面所有位抵消。

假设第一个不同位在小数点后第 k 位。由于编码保持字母顺序，该位给较大一方带来的优势至少为：

10−k.

在字符对应的数位上，每位最多相差 3 − 1 = 2。即使把后面的每一位都安排成对较小一方最有利，能追回的量也至多为：

2 × 10−(k+1) + 2 × 10−(k+2) + …
= 29 × 10−k < 10−k.

所以，后面的位追不上第一个不同位带来的差。对于等长有限字符串，双方末尾都补 0，尾部的影响只会更小；对于无限字符串，上面的无限和直接适用。

因此：对于我们要比较的等长有限字符串，以及无限字符串，字典序比较与对应小数的比较完全一致。相同字符串对应相同小数，不同字符串也不会对应同一个小数。

3. 拼接字符串，对应怎样的小数运算？

设 s 长 m 位，t 长 n 位。记它们对应的有限小数为：

α = F(s),    β = F(t).

把 t 接在 s 后面，就要把 β 的所有数位向右移动 m 位，即乘以 10−m，然后加到 α 后面：

F(st) = α + 10−mβ,
F(ts) = β + 10−nα.

例如，s = ab、t = aba，则 α = 0.12、β = 0.121：

F(ababa) = 0.12 + 0.00121 = 0.12121,
F(abaab) = 0.121 + 0.00012 = 0.12112.

注意移动的位数：拼 st 时，t 要移过 s 的 m 位；拼 ts 时，s 要移过 t 的 n 位。移动后两个有限小数占据不同的位置，因此相加正好实现拼接。

现在把两者相减，并把这个差记作 D：

D = F(st) − F(ts)
= α + 10−mβ − β − 10−nα
= α(1 − 10−n) − β(1 − 10−m).

D < 0，就说明 st < ts；D = 0 或 D > 0 时同理。

4. 无限重复，对应怎样的小数运算？

无限重复 s，就是在第一块 s 后面，不断添加右移 m、2m、3m、… 位的同一块小数：

F(s∞) = α + 10−mα + 10−2mα + …

例如，s = ab 时：

F(ababab…) = 0.12 + 0.0012 + 0.000012 + …
= 0.121212…

这些项构成等比级数：首项为 α，公比为 10−m。由“无限和 = 首项 ÷（1 − 公比）”，得到：

F(s∞) = α1 − 10−m,    F(t∞) = β1 − 10−n.

这里的 α、β 始终是小数。例如 F((ab)∞) = 0.12 ÷ 0.99。用分数写出循环小数的值，只是在进行实数运算，没有改用字符串的整数编码。

5. 两种比较的差，只相差一个正数因子

将两个无限小数相减，并通分：

F(s∞) − F(t∞)
= α1 − 10−m − β1 − 10−n
= α(1 − 10−n) − β(1 − 10−m)(1 − 10−m)(1 − 10−n).

蓝色的分子，正好就是第 3 步得到的 D = F(st) − F(ts)。因此：

F(s∞) − F(t∞)
= F(st) − F(ts)(1 − 10−m)(1 − 10−n).

因为 m、n ≥ 1，分母恒为正数。除以一个正数，不会改变差的正负，也不会改变它是否为零。

于是，两组小数的大小关系一致。再利用第 2 步证明的“编码保持字典序”，就得到：

st < ts   ⇔   s∞ < t∞.

等号和大于号同样成立。证明完毕。 □

6. 把同一个例子从头算完

仍取 s = ab、t = aba。有限拼接对应的小数之差为：

F(st) − F(ts) = 0.12121 − 0.12112 = 0.00009 > 0.

无限重复对应的小数之差为：

0.120.99 − 0.1210.999
= 0.12 × 0.999 − 0.121 × 0.990.99 × 0.999
= 0.000090.99 × 0.999 > 0.

直接看小数，也能在第 4 位找到相同的大小关系：

比较对象第一方第二方结果
有限拼接0.121210.12112第一方更大
无限重复0.121212…0.121121…第一方更大

7. 如果不止三个字母呢？

上面用三个字母和十进制，是为了让小数直观可读。对于任意含 K 个字符的有限有序字符集，将字符依次编码成 1、2、…、K，选择 B = K + 2 进制即可。

此时，“小数”仍然是各位数字乘以各位权重的和，只不过第 k 位的权重变成 B−k。后续位的最大影响为：

K − 1B − 1 · B−k < B−k.

所以编码仍然保持顺序。把整篇证明中的 10 全部换成 B，就得到一般结论，核心等式变为：

F(s∞) − F(t∞)
= F(st) − F(ts)(1 − B−m)(1 − B−n).

例如 26 个小写字母可以用 28 进制；27 进制也可以。较大的进制只是让每个编码都能放进一个数位，并确保尾部无法抵消首个不同位的差，不改变证明思路。非空条件保证 m、n 为正，也保证这里的无限重复和分母有意义。
