字符串怎么能拿来比较实数？

先暂时放下 28 进制和拼接公式。我们只用三个字母和熟悉的十进制，弄清楚“把字典序比较转化为实数比较”究竟在做什么。

这句话的意思是：给每个无限字符串指定一个实数，而且保证字符串谁在字典序中更小，它对应的实数也更小。这样，就可以用数的运算来研究字符串的顺序。

1字典序只看第一个不同的位置

假设只有 a、b、c 三种字符，顺序是 a < b < c。比较两个字符串时，从左往右看，跳过相同的字符，在第一个不同的位置决定大小。

a b b c c …
a b c a a …

前两位相同，第 3 位是 b < c，所以第一行更小。第 3 位之后出现什么，都不能改变字典序的结果。

我们要构造的实数也必须具有这个性质：靠前的第一个差异，足以压过后面的所有差异。

2回忆：小数是一串“带权重的数字”

十进制小数 0.123 的含义是：

0.123 = 1 × 110 + 2 × 1100 + 3 × 11000
小数点后的位置第 1 位第 2 位第 3 位第 k 位
这一位的权重0.10.010.00110−k

越靠后，权重越小。无限小数也是同样的意思，只是把这些贡献一直加下去。

例如，0.121212… 对应的实数，是 0.1、0.12、0.121、0.1212、… 这些有限小数逐渐接近的那个值，数学上叫它们的极限。这里的极限存在，因为这些数一直增加，又不会超过 1。

所以，无限小数并不是“一个永远写不完、因此没有值的东西”。它是一种表示实数的方式，例如 0.333… = 1/3。

3给无限字符串指定一个实数

我们自己规定下面的编码，并保持字母原来的大小顺序：

a → 1
b → 2
c → 3

然后，把无限字符串的每个字母换成对应数字，并在最前面加上 0.：

abccaa…   →   0.123311…

把这条规则记作 F，那么 F(abccaa…) = 0.123311…。这里的 F 就是一台“字符串输入、实数输出”的机器。

不是说字符串本来就是一个数。这是我们人为选择的一种对应规则。要用它证明结论，还必须证明它保持顺序：u < v ⇔ F(u) < F(v)。

4关键：后面的数字为什么不能反超？

先看一个具体例子。两个字符串的前两位一样，第 3 位分别是 b 和 c。我们故意把较小一方的后续字符全部设成最大的 c，把较大一方的后续字符全部设成最小的 a：

abbccc… → 0.122333…
abcaaa… → 0.123111…

第 3 位从 2 变成 3，给第二个数带来了 0.001 的优势。后面的位则一直在帮第一个数追赶，但它们最多追回：

0.0002 + 0.00002 + 0.000002 + …
= 0.000222… < 0.001

连这种对第一方最有利的尾部都追不上，其他尾部就更不可能。因此，实数比较也由第一个不同位决定。

换成任意位置，道理完全一样

假设第一个不同位是第 k 位。该位的数字至少相差 1，产生的优势至少是 10−k。后续每位最多相差 3 − 1 = 2，全部尾部能追回的量至多为：

2 × 10−(k+1) + 2 × 10−(k+2) + …
= 29 × 10−k < 10−k

这里用了等比级数：首项为 A、公比为 r，且 0 < r < 1 时，无限和为 A/(1 − r)。本例首项为 2 × 10−(k+1)，公比为 1/10。

至此才证明了“可以转化”：字符串在第一个不同位决定的大小，与它对应的小数的大小一致。不同字符串也不会被映射到同一个实数；相同字符串则显然对应同一个实数。

6现在再看 28 进制，就没有新概念了

上面只用了三个字母，所以十进制足够。如果要把 26 个字母编码成 1 到 26，十进制就不够了：十进制的单个数位只能是 0 到 9，不能把 26 当作一个数位。

B 进制只是把每一位的权重从 10−k 换成 B−k。为了避免把一个数位中的 26 误读成两个数位，可以这样写：

F(azb…) = 1 × 28−1 + 26 × 28−2 + 2 × 28−3 + …

原理仍然是“首个不同位的优势，大于全部尾部可能追回的量”。此时每位最多相差 25，于是：

尾部最大影响 = 2527 × 28−k < 28−k

28 没有特殊含义。用 1 到 26 编码时，27、28、29 等进制都可以；27 进制中对应的比例为 25/26 < 1，同样成立。

7它怎样帮我们证明原来的结论？

对于无限重复 s∞，上述规则恰好把它变成一个循环小数。循环小数可以通过等比级数写成分数，这就让字符串问题变成了可以通分、相减的代数问题。

例如，在我们的三字母十进制例子中，取 s = ab、t = aba：

F(s∞) = 0.121212… = 1299
F(t∞) = 0.121121… = 121999

比较这两个分数，通分后分子的差为：

12 × 999 − 121 × 99 = 9 > 0.

于是 F(s∞) > F(t∞)。由于我们已经证明 F 保持顺序，就能得出 s∞ > t∞。

再看拼接：st = ababa 编码为整数 12121，ts = abaab 编码为整数 12112，它们的差也是 9。原证明就是把这个例子中的计算推广到任意非空字符串。

整个证明的桥梁：
无限字符串 → 按位编码的小数 → 证明保持大小关系 → 用分数运算比较 → 把结果翻译回字典序。

范围提醒：这里的 F 针对无限字符串。原证明对有限的 st、ts 使用整数编码，是因为它们长度相等。不要直接拿不同长度字符串对应的整数比较字典序，例如 aac < b，但整数 113 > 2。
